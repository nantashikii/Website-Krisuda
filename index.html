MY REASON

Turning ideas into reality.

Saya memilih Program Studi S1 Pendidikan Teknik Informatika karena sejak sekolah saya sudah memiliki ketertarikan terhadap dunia programming dan teknologi.

Bagi saya, programming bukan hanya tentang menulis kode. Programming adalah cara untuk memecahkan masalah, menciptakan sesuatu, dan mengubah sebuah ide menjadi sebuah karya yang dapat digunakan.

Ketertarikan tersebut pernah saya kembangkan melalui sebuah lomba karya aplikasi fiksi dan berhasil mendapatkan juara 1 .

Pengalaman tersebut membuat saya semakin yakin untuk mendalami dunia teknologi, khususnya programming dan pengembangan aplikasi.

Di Undiksha, saya ingin terus belajar, bereksperimen, mengembangkan kemampuan, dan suatu hari mampu menciptakan teknologi yang dapat memberikan manfaat bagi banyak orang.
